#Downloads Organizer 
Downloads Organizer is a stand-alone organization file that organizes your downloads into folders by file type. It runs in the background with a system tray icon and includes desktop notifications, pause/resume controls, and auto-run on Windows startup.

*Features:*

Automated File Organization: Instantly moves downloaded files into sub-folders (Images, Documents, Installers, Archives, 

*Requirements:*

Python: Python 3.8+ (must be added to system PATH).

Installation:
   - Double-click setup.bat.
   - This script will install required dependencies from requirements.txt and create a shortcut in your Windows Startup folder so it runs every time you log in.

3. Manual Setup:
   If you prefer to install dependencies manually, run:
   pip install -r requirements.txt
